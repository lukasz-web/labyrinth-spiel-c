# Labyrinth-Spiel in C

Praxisarbeit im Modul **Programmiertechnik A & B**.

## Beschreibung

Dieses Projekt ist ein textbasiertes Labyrinth-Spiel in der Programmiersprache C.

Der Spieler bewegt sich mit **W, A, S und D** durch ein 10 × 10 grosses Spielfeld und versucht, einen zufällig platzierten Schatz zu finden. Hindernisse können nicht betreten werden.

## Steuerung

- W = Hoch
- A = Links
- S = Runter
- D = Rechts
- Q = Spiel beenden

## Kompilieren

```bash
gcc main.c -o labyrinth
```

## Starten

```bash
./labyrinth
```
